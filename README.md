# Klaro — Your Medical Timeline

A patient-first medical records and
AI reasoning tool for managing complex
chronic conditions.

## What It Does
- Upload medical report PDFs
- AI extracts structured data automatically
- Chronological medical timeline with filters
- Patient name and condition tagging
- Secure per-user data with authentication

## Live Demo
https://klaro-6cd64.web.app

## Tech Stack
- React + Tailwind CSS
- Supabase (Postgres + Storage + Auth)
- Gemini AI (PDF extraction + reasoning)
- Firebase Hosting
- Google Antigravity IDE

## Status
Active development — Phase 1 and
authentication complete.
Phase 2 (AI reasoning layer)
in progress.

Built to solve a real problem —
